# Scientific assumptions and limitations

## Current release

FieldShift makes no scientific calculation, agronomic prediction, yield estimate, or soil-improvement claim in this release. It has no connected observational dataset and no crop rules.

## Principles for future calculations

- Use documented inputs with units and provenance.
- Prefer deterministic rules that name their inputs, thresholds, and reasons.
- Distinguish missing data from a negative agronomic result.
- Treat outputs as decision support, not guarantees or prescriptive advice.
- Seek suitable local agronomy review before presenting rules as supported guidance.
- Communicate uncertainty, data coverage, and limitations beside results.

Specific thresholds, crop relationships, and research claims will appear here only after their sources are verified.
